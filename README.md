# Simple Vue CRUD Application

This is a simple CRUD application built with Vue 3 and TypeScript.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository:
    ```sh
    git clone <repository-url>
    cd <repository-directory>
    ```

2. Install the dependencies:
     ```sh
    npm install
    ```

### Running the Application

Start the development server:
```sh
npm run dev
```

The application should now be running at http://localhost:5173

## Project Description
This project is a simple CRUD (Create, Read, Update, Delete) application. It allows users to manage a list of users, including adding new users, updating existing users, and deleting users. The application is built using Vue.js and TypeScript, and it uses PrimeVue for UI components.
